All notable changes to Synth Warp are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/) (pre-1.0: breaking changes bump the minor version).
Upstream Warp changes merged into the fork are summarized, not itemized.

## [Unreleased]

## [0.3.0] — 2026-11-19

### Added

- Self-hosted remote control: share terminals with a server you run (`synth-remote-control-server`, now in `synthet/warp-remote`) and control them from a phone or browser; point the app at it with `SYNTH_WARP_REMOTE_CONTROL_URL`.
- Synth Term app icon: a silver terminal window frame with a `>_` prompt, for the app, the Windows installer images and the `oss`, `warp-oss` and `local` channels, regenerated by `script/apply_branding_icons.py` from `assets/branding/synth-term/`.
- License notice `legal/synth-warp-notice.md` (AGPL-3.0-only and MIT, source location, no warranty, non-affiliation with Warp), plus attribution and trademark notes in the README.
- Bundled themes have plain, unique display names.
- Resumable Windows compile scripts (`script/windows/build.ps1`) that retry with fewer jobs after an out-of-memory crash.

### Changed

- Windows: `script/windows/deploy.ps1` installs per user into `%LOCALAPPDATA%\Programs\SynthWarp`, side by side with official Warp, with its own Start menu shortcut and Explorer entries. It no longer overlays `C:\Program Files\Warp`.
- The OSS build no longer asks users to agree to Warp's Terms of Service. The `oss` installer, exe version resource, macOS bundle and Linux packages name the fork as publisher, credit Denver Technologies, Inc. as the original copyright holder, and give `AGPL-3.0-only AND MIT` as the license.
- Warp-hosted cloud agents (Oz), Warp-hosted AI settings and Warp Inc. links are gated off in the OSS channel.
- Telemetry stays on the machine; nothing is exported to Warp.
- Merged upstream `warpdotdev/warp` up to `abb3fe33` (2026-11-06).

### Fixed

- Windows: session tabs survive an OS restart, shutdown or sign-out instead of being closed one by one as the shells are killed.
- Windows: the Claude Code hooks installer runs with a process-scoped `Bypass` execution policy, merges existing hooks instead of overwriting them, and PowerShell hooks replace the bash plugin.
- Windows: git context-chip probes no longer leak PowerShell processes or retry failed probes.
- Windows: process spawn retries without `CREATE_BREAKAWAY_FROM_JOB` where the job forbids it.
- GraphQL requests short-circuit to the disabled server root instead of reaching Warp's servers.
- The pink-city theme loads again; expected empty-state warnings are logged at debug level.

## [0.2.0] – 2026-08-14

### Added

- Synth Warp: a local-first, commercial-free fork of Warp's open-source client, without billing, upgrades, credits, referrals, Warp Drive cloud sync or hosted Warp AI.
